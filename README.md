# Netflix Show Popularity Prediction

Predicting the popularity score of Netflix shows using Age, Cast Size, Genre, and Duration.

## Project Structure
- `data/`: Synthetic dataset matching Netflix titles schema.
- `models/`: Trained regression models.
- `plots/`: Evaluation charts.
- `src/`: Code modules.

## Features
- **Content Age**: How old is the show?
- **Cast Size**: Number of actors listed.
- **Genre Count**: Diversity of genres.
- **Duration**: Length of the movie/show.

## Installation
```bash
pip install -r requirements.txt
```

## Usage
Run the pipeline:
```bash
python main.py
```
