# Netflix Show Popularity Analysis

## Overview

This project analyzes Netflix shows to determine patterns influencing show popularity using data analysis and machine learning techniques. The objective is to identify key factors that contribute to higher audience engagement and ratings.

The system performs exploratory data analysis, feature engineering, and predictive modeling to evaluate show popularity based on attributes such as genre, release year, cast, duration, and content type.

---

## Problem Statement

With thousands of shows available on Netflix, understanding what drives popularity is essential for:

- Content recommendation systems
- Production decision-making
- Marketing strategy optimization
- Viewer engagement prediction

This project aims to analyze historical Netflix data and build predictive insights around show success.

---

## Dataset

The dataset contains information such as:

- Show ID
- Title
- Genre
- Director
- Cast
- Country
- Release Year
- Duration
- Rating
- Type (Movie / TV Show)

Data preprocessing includes:
- Handling missing values
- Encoding categorical features
- Feature selection
- Data normalization
